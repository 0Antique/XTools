XTools 0.2.0 改善了剪贴板图片、窗口操作和资源管理器文件带入。

- 微信复制的临时图片按内容解码，保存为独立 PNG，并显示更大的缩略图。
- 右上角新增悬浮开关：开启后置顶，关闭后点击外部隐藏。
- 每次呼出重新定位到主显示器；首页支持四向键盘导航。
- 资源管理器选中文件后按 Alt + Space，打开批量重命名即可带入新批次；新批次替换原列表。
- 重命名规则区使用淡蓝背景，简化了指定界面文案。
- 取色使用 DIB 缓冲采样和双缓冲绘制；成功复制后发送包含 HEX 的 Windows 系统通知。

下载附件 **XTools_Setup.exe** 后直接运行，无需解压。支持 Windows 10 1703+ / Windows 11 原生 x64，需要预先安装 WebView2 Runtime。升级保留个人设置、历史和收藏；卸载继续保留 AppData 中的数据。

具体实测结果与尚未覆盖的环境见仓库 `docs/ACCEPTANCE.md` 的 V2 部分。GitHub 自动生成的源码链接属于平台功能。
