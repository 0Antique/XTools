XTools V2.1 简化了启动器界面。

- 移除剪贴板、屏幕取色、批量重命名卡片上的字母提示和回车图标。
- 移除首页底部的方向键、Enter、Esc 提示及设置入口整行。
- 设置按钮移动到右上角，位于悬浮按钮左侧。

发布版本为 **V2.1**，标签 **v2.1**；工程和安装器使用三段版本号 **2.1.0**。

下载附件 **XTools_Setup.exe** 后直接运行，无需解压。支持 Windows 10 1703+ / Windows 11 原生 x64，需要预先安装 WebView2 Runtime。升级保留个人设置、历史和收藏；卸载继续保留 AppData 中的数据。

具体实测结果与尚未覆盖的环境见仓库 `docs/ACCEPTANCE.md` 的 V2 部分。GitHub 自动生成的源码链接属于平台功能。
